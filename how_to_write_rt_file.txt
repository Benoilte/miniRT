HOW TO WRITE A .rt FILE

Only one element should be defined on a line

◦ Each type of element can be separated by one or more line break(s).
◦ Each type of element can be set in any order in the file.
◦ Each type of information from an element can be separated by one or more space(s).
◦ Each type of information from an element should respect its specific order.

◦ first information from an element is its identifier.
◦ element: [identifier]	[specific_information].

Elements [A] [C] [L] should be present once in the scene

	Ambient lighting:

		A	[ratio]			[color]

	Camera:

		C	[position]		[orientation]	[fov]

	Light:

		L	[position]		[ratio]			[color]

	Sphere:

		sp	[position]		[diameter]		[color]

	Plane:

		pl	[position]		[orientation]	[color]

	Cylinder:

		cy	[position]		[orientation]	[diameter]		[height]	[color]

Definition:

	[ratio]			=> 	[float]	in range	[0.0, 1.0]		example:	[0.2]
	[position]		=>	[x,y,z]								example:	[0.0,0.0,0.0]
	[orientation]	=>	[x,y,z] in range	[-1.0, 1.0]		example:	[0.0,0.0,1.0]
	[color]			=>	[R,G,B] in range	[0, 255]		example:	[255,255,255]
	[fov]			=>	[float]	in range	[0, 180]		example:	[90]
	[diameter]		=>	[float]								example:	[2]
	[height]		=>	[float]								example:	[4]

Bonus part:

	Resolution

		R	[windo_width]		[window_height]

	Reflective and refraction depth

		D	[reflective_depth]	[refraction_depth]

	Anti-Aliasiing precision

		AA	[precision]

	Material default for all shape

		M	[diffuse_ratio]		[specular_ratio]	[shininess]	[reflective_ratio]	[transparency_ratio]	[refractive_index]

	cube

		cu	[position]			[orientation]		[width]		[height]			[length]				[color]					[material]

Definition:

	[windo_width]			=>	[int]							example:	[960]
	[window_height]			=>	[int]							example:	[720]
	[reflective_depth]		=>	[int]	in range	[0, 20]		example:	[3]
	[refraction_depth]		=>	[int]	in range	[0, 10]		example:	[3]
	[precision]				=>	[int]	in range	[0,2]		example:	[2]
	[diffuse_ratio]			=>	[float]	in range 	[0.0, 1.0]	example:	[0.9]
	[specular_ratio]		=>	[float]	in range 	[0.0, 1.0]	example:	[0.9]
	[shininess]				=>	[float]	in range 	[10, 200]	example:	[200]
	[reflective_ratio]		=>	[float]	in range 	[0.0, 1.0]	example:	[0.4]
	[transparency_ratio]	=>	[float]	in range 	[0.0, 1.0]	example:	[0.7]
	[refractive_index]		=>	[float]	in range 	[0, 3]		example:	[1.33]
	[width]					=>	[float]							example:	[4]
	[height]				=>	[float]							example:	[2]
	[length]				=>	[float]							example:	[8]
	[material]				=> 	at the end of each shape we can add the six value of material to overide material [M] default settings
